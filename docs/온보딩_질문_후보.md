## 2. 뺀 것 / 뺀 이유

- **옵션 "영어 실력 잃지 않게" 제거**
  PRD Problem Statement, Product Goals, Future Roadmap 어디에도 "실력 유지/retention" 관련 문제나 기능이 없습니다 (스트릭, 복습 알림, 망각곡선 같은 기능은 MVP는 물론 Phase 1~5 로드맵에도 없음). 이 답을 받아도 지금 설계된 화면 중 달라질 수 있는 부분이 없어서 제외합니다.

- **질문 "현재 오픽 수준" 전체 제거**
  세 가지 이유입니다.
  1. 초안 옵션에 **"오픽 시험 본 적 없음"이 첫 번째와 마지막에 중복**으로 들어가 있습니다 (버그로 보입니다).
  2. PRD에는 topics 테이블에 `difficulty` 컬럼이 있지만 "향후 확장용 컬럼"이라고 명시되어 있고 현재 미구현입니다 (14번 섹션). 즉 지금 시점엔 "현재 수준"에 따라 문항 난이도나 화면을 분기할 기능 자체가 없습니다.
  3. "목표 오픽 성적" 질문과 의미가 겹쳐서, 온보딩 질문 수만 늘고 개인화에 쓸 수 있는 정보는 거의 늘지 않습니다.
  → 난이도 분기 기능이 실제로 생기는 시점(Phase 3 "학습 통계 및 진단 리포트" 등)에 다시 넣는 걸 추천합니다.

- **질문 "이 서비스에서 기대하는게 무엇인가요?"의 옵션 통합**
  "영어 오픽 성적 받기"와 "내 오픽 수준 알기"는 둘 다 PRD의 "예상 OPIC 레벨" 기능(User Story, Result Page 레벨 카드) 하나를 가리키는 사실상 같은 응답이라 하나로 합쳤습니다.

- **새 질문(Problem 축) 1개 추가 제안**
  초안 3개 질문은 Purpose·Expectation 축에는 있지만 "지금 어떤 문제를 겪고 있는가"를 직접 묻는 질문이 없었습니다. PRD Problem Statement(7번 섹션)에 실제로 적힌 6개 항목 중 화면 분기와 연결 지을 수 있는 4개를 옵션으로 하는 질문을 새로 제안합니다. (원치 않으면 이 질문은 빼고 3개만 가도 됩니다.)

## 4. 요약

- 무조건 포함 추천: **Purpose 1개 + Expectation 1개** (총 2문항, 옵션 3+4=7개)
- Problem 질문은 선택 사항입니다 — 넣으면 3문항(3~5개 범위 충족), 온보딩을 더 짧게 가고 싶으면 빼도 됩니다.
- 표에서 최종 3~5개를 골라 알려주시면 그에 맞춰 온보딩 화면(폼/저장 스키마) 구현으로 넘어가겠습니다.
